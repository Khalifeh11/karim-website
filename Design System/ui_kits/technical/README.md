# UI Kit · Direction B — Technical

The modern-operator portfolio. All-Geist, near-white / near-black, electric blue. Vercel/Linear/Resend adjacent — but quieter.

## Files

- `index.html`, `styles.css` — entry + visual layer
- `components.jsx` — Header, Footer, StatusPanel, ProjectRow, etc.
- `pages.jsx` — Home, Work, CaseStudy, About, Contact
- `main.jsx` — App shell, state router, dark-mode toggle

## Distinguishing features

- Hero is split: copy on the left, a live-looking **status panel** on the right (location, availability, current project, last commit).
- Work is presented as a **list**, not a grid — emphasizes scale and rapid scanning.
- Mono fonts are part of the chrome (filename strips, line numbers in section headers).
- Border-heavy layout; flat surfaces; zero shadows except for the theme pill.
