# UI Kit · Direction C — Studio

The studio-of-one portfolio. Bricolage Grotesque + Geist + JetBrains Mono. Bone background, deep forest accent. The most personality of the three.

## Files

- `index.html`, `styles.css`
- `components.jsx` — Header, Footer, ProjectFeature, ProjectMini, etc.
- `pages.jsx` — Home, Work, CaseStudy, About, Contact
- `main.jsx`

## Distinguishing features

- The hero is asymmetric — display headline + meta-line stacked, with a date-stamped "studio note" pinned to the side.
- The work grid leads with **one large featured project** then three smaller in a row underneath — visual hierarchy of importance.
- A soft radial vignette warms the hero background.
- Section dividers are labeled (`— note one —`, `— note two —`) like a journal.
- The monogram is the only place where the display serif personality really lives.
